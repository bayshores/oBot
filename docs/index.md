# openbot

openbot is a desktop app for chatting with AI assistants ("Bots") that run on your own computer
with Claude Code. Each Bot has its own chat, memory and routines, can use the computer's tools, and,
if you connect them, can help with your Gmail / Google Calendar or Outlook email and calendar.

- Source code and setup: [github.com/bayshores/openbot](https://github.com/bayshores/openbot)
